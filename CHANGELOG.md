# Change Log

All notable changes to the SFX Language Support extension will be documented in this file.

## [0.3.2] - 2025-12-06

### Changed
- Updated for SFX v0.3.2
- File extension changed from .mon to .sfex
- Project renamed from Mono to SFX (Situation Framework eXchange)

### Added
- Enhanced syntax highlighting for new language features
- Support for FastNumber, Option, WeakRef types
- Better highlighting for reactive When observers

### Fixed
- Improved bracket matching
- Better indentation detection

## [0.3.0] - Previous Release

### Added
- Initial release
- Basic syntax highlighting
- Language configuration
- Support for .mon files
